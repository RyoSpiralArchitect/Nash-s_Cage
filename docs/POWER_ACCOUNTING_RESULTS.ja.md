# 石油から実データへ：燃料炭素会計の初回実行

2026-09-05。入力契約0.1に対する最初の会計実装。
対象は日本の2024年度・事業用発電（揚水発電除く）`#241000`。
v0.2〜v0.4のモデル・係数・固定試験は変更しない。

## 何が分かったか

公表統計の21燃料区分を保持して実行した。**17区分は投入熱量×炭素係数と
公表炭素投入量が一致、1区分は不一致、3区分は対応未確定**だった。
一致は会計の内部整合性であり、独立した煙突測定や理論の実証ではない。
使用統計とNID係数は共通の算定系統に依存し得る。

| 照合状態 | 燃料 | 扱い |
|---|---|---|
| 一致：17 | 発電用一般炭、発電用C重油、LNG等 | 条件を固定した炭素会計を再現 |
| 不一致：1 | 軽油 `$0434` | 棄却したまま、残差を保存 |
| 対応未確定：3 | 発電用高炉ガス `$0224`、アスファルト `$0453`、他重質石油製品 `$0454` | 親区分の係数を推測で流用しない |

軽油の原油由来係数を使うと、公表値より18.816513328 tC大きくなる。
別行の「バイオマス考慮」係数なら数値上は一致する。ただし混合比や
適用範囲の裏付けまで確認したわけではないため、採用判定は変えていない。
21区分は化石燃料系の6親区分と投入熱量・炭素量の合計が閉じる。
親区分を重ねて加算せず、バイオマス等も含む全燃料の網羅とは呼ばない。

## 石油を先に見る、ただし逼迫順位はまだ決めない

次の具体的な入口を **発電用C重油 `$0440`** とする。
これは対象選択であり、全国で石油が最も不足しているという推定結果ではない。
石油は原油・重油・軽油・LPG等で性質、用途、輸送・貯蔵条件が異なる。
「石油等」という全国の年次合計では、現場で使える燃料量を表せない。

政府の[石油火力に関する資料](https://www.meti.go.jp/shingikai/enecho/denryoku_gas/jisedai_kiban/pdf/005_07_00.pdf)
は、離島供給や系統運用上の役割を挙げる。一方、FY2024全国集計の発電量は
石炭2,785億kWhに対し石油等711億kWhであり、石炭は排出規模を見る上では小さな対象ではない。
ただし、この全国値と本実装の事業用発電の母集団は異なる。
[FY2024確報概要](https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040391289&fileKind=2)

したがって「排出規模」と「供給途絶時の局地的な脆弱性」は別軸にする。
2026年9月時点の油種別・地点別在庫、配送予定、消費予測は今回取り込んでいない。
年度投入量から現在の在庫や枯渇日を計算しない。

## 1 TJを動かしたとき、言える量／言えない量

| 燃料 | 1 TJ-HHVに含まれる炭素の全量CO₂換算 [t-CO₂] |
|---|---:|
| 発電用一般炭 `$0123` | 90.783680883 |
| 発電用C重油 `$0440` | 72.896383438 |
| LNG `$0510` | 50.746998913 |

これは `1 × 炭素係数 × 44/12`。1 TJは算定例の量であり、同じ電力量ではない。
効率、起動停止、所内消費、混焼、代替機、送電制約は未同定。
この差をそのまま「燃料転換で削減できるCO₂」や政策効果にしない。
燃料別の送電端MWhが結べていないため `tCO₂/MWh` も出力しない。

NIDの `1.A.1.a 発電・熱供給` を全国9,911億kWhで割る結合は引き続き
`REJECT_SCOPE_MISMATCH`。パリ協定・NDCから発電部門の予算を自動配分しない。

## 次の一対象・一作用・一資源

会計対象は全国統計だが、実行可能性の対象はまだ一機へ絞れていない。
次の入力契約を石油向けに用意する。実在する機・系統・期間を選定するまでは未同定。

| 項目 | 次に確認する入力 |
|---|---|
| 一対象 | 指定供給区域のC重油対応発電機1基。設備ID、燃料規格、混焼/CHP等の除外条件 |
| 一作用 | 指定時間窓で当該機の燃料消費を減らし、同じ受渡点・各制御刻みの電力サービスを維持する比較 |
| 一資源 | 当該機に実際に使用可能なC重油在庫 [TJ-HHV]。他用途への約定分・最低保有量を除く |
| 資源更新 | 前刻在庫＋確認済み受入−当該機消費−他の払出。配送遅延、油種、荷揚げ・貯蔵上限を別記 |
| 別途必要な制約 | 当該機の減出力余地、代替機・送電の追加余力、最低出力、起動・増減速、予備力、需要 |

前案のLNG追加送電可能量 `R_t [MWh]` と異なり、石油在庫には物理的な繰越がある。
同じ資源変数を単位だけ替えて流用しない。全国原油備蓄を当該機の使用可能重油へ
直結しない。「一資源」は他の資源が無限という仮定でもない。

## 再実行

```bash
make power-accounting
make verify-power
```

前者は新規 `.tmp/power-accounting` へ作成し、既存出力は上書きしない。
再実行時は `python3 tools/run_power_accounting.py run --out .tmp/power-second-run`
のように別の出力先を使う。

[出典・抽出契約・原本再照合の手順](../data/power_jp_fy2024/README.md)、
[全21区分の比較](../artifacts/power_jp_fy2024/comparison.md)、
[機械可読の結果](../artifacts/power_jp_fy2024/summary.json)、
[ハッシュ付き実行記録](../artifacts/power_jp_fy2024/receipt.json)。

本データは年次会計の入口であって、校正済みデジタルツインではない。
繰り返し計算しても、未観測の在庫や限界応答は増えない。
大量実行は地点・時刻別の入力契約が閉じてから、固定した欠損・遅延・供給途絶の
ケースを比較する段階に進める。
