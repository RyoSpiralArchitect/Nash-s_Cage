# 前払いで誰が間に合い、誰の機会が残ったか

2026-11-04 JST。**固定した36,864の人工世界で4条件を全列挙し、炉で再計算も一致した。**
これは制度の効果を推定する試験ではなく、事前記録から判定できることを確かめるF0の有限モデル試験。
世界の件数は、現実の発生頻度、成功確率、独立標本数ではない。

## 期限に間に合うことと、その費用を支えられること

主比較は、同じ名目給付を通常時点に予定する場合と前払いする場合の差である。
対象者の期限内完了が増えたのは **960 / 36,864世界**。その960世界を重複なく分けた。
「他の機会」は同じ支払元・設備を使う別の追加保護サービスであり、全条件で確保済みの既存保護枠とは別。

| 対象者の完了が増えた世界に何が起きたか | 世界数 |
|---|---:|
| 他の機会を減らさず、対象者の保護が資金面で次期まで続き、未払も増えない | 96 |
| 他の機会が失われた（継続・未払の条件は満たす） | 448 |
| 他の機会は残ったが、継続できず未払が増えた | 96 |
| 他の機会が失われ、継続できず未払も増えた | 320 |
| 合計 | 960 |

したがって、960世界中、他の機会の喪失は768、継続失敗と未払悪化は416。**320世界が重なる**。
「不合格」には改善なしも含み、全てを有害と判定したわけではない。一方、対象者に改善がない世界にも
押し出しはあり、全36,864世界で他の機会が減るのは12,096世界である。
これは不実行でも給付が予定されるという契約の下での計数であって、実在制度の損失ではない。

### 対象者の完了だけから、流動性の救済とはいえない

| 通常条件での介入前分類 | 世界数 | 前払いで対象者の完了増 | 全診断条件を満たす |
|---|---:|---:|---:|
| 資金制約あり C | 3,072 | 672 | 96 |
| 資金制約なし U | 9,216 | 288 | 0 |
| 権限または現物の不足で不適格 | 24,576 | 0 | 0 |

追加の内訳確認：Uで完了が増えた288世界は、**288全てで他の機会が1から0へ減った**。
いずれも設備は1枠、配分は他の機会が先、支払元の初期残高は1。通常なら他の機会が先に枠を使うが、
前払いで支払元の残高がなくなると、その機会は実行できず、対象者へ枠が移る。
同じ「対象者が間に合った」でも、受取側の資金不足が解消されたという説明にはならない。

## 事前記録を増やすと、何が区別できるか

「判定が割れる」とは、その時点で観測する項目が全く同じなのに、全診断条件を満たす世界と
満たさない世界が両方残ること。左の分母は**記録の種類**、右の分母はつねに**36,864世界**。

| 利用する事前記録（上から累積） | 判定が割れる記録の種類 / 全種類 | そこに属する世界数 | 楽観的に補完した場合の誤った肯定 / 肯定数 |
|---|---:|---:|---:|
| 権限・手元資金 | 1 / 4 | 9,216 | 9,120 / 9,216 |
| ＋ 引出可能信用・手数料 | 2 / 16 | 4,608 | 4,512 / 4,608 |
| ＋ 設備・履行見込み・利得条件 | 2 / 192 | 384 | 288 / 384 |
| ＋ 支払元の残高・補充・配分順 | 8 / 1,536 | 192 | 96 / 192 |
| ＋ 次期の継続費用・確定収入 | 0 / 9,216 | 0 | 0 / 96 |
| 全モデル入力（確約の整備費・信用供与も含む） | 0 / 36,864 | 0 | 0 / 96 |

主比較の楽観的補完による見逃しは各段階とも0。楽観的補完の肯定数と未識別世界数は**別の指標**である。
受取側金融を知っても、追加の保護まで増やせるとは断定できない。指定した観測順では、**継続の記録を
加えた段階で、前払いの判定の混在がなくなった**。確約関連の2項目はこの比較では作動しない。
この順が最適、全項目が現実で必須・取得可能、または判定の確定が現実の安全を意味するとはいえない。

### 結論が割れる二組の反例

固定順で出力された[反例の組](../../../artifacts/executability_twins_v01/enumeration_20261104/witnesses.json)から、主比較の二組を読む。

- **支払元の残高だけが違う**（`w004512` と `w004416`）。受取側の信用・現物・行動条件は同じ。
  いずれも前払いで対象者の完了は0→1。支払元に2単位ある世界では他の保護も1→1、1単位しかない世界では
  1→0となる。後者の通常払いでは給付自体も未払になる。名目額が同じでも実際の受領額は同じとは限らない。
- **継続費用だけが違う**（`w004512` と `w004520`）。支払元の残高はともに2、次期の確定収入はともに0。
  どちらも対象者の完了は0→1、他の機会は1→1。維持費0なら続くが、維持費1では1単位未払となり続かない。

## 副比較を主比較と混ぜない

| 比較（全て通常払い・追加確約なしに対して） | 世界数 | 対象者の完了増 | 全診断条件を満たす |
|---|---:|---:|---:|
| 前払い | 36,864 | 960 | 96 |
| 履行確約 | 36,864 | 2,640 | 464 |
| 前払い＋履行確約 | 36,864 | 3,840 | 304 |

最後の確約関連2項目を伏せた段階では、確約・併用の各比較にはなお608世界ずつの判定混在が残る。
確約が信用も変えたり整備費がかかったりするため、順位や純粋な心理効果とは読まない。
全入力で混在がゼロになるのは決定論的な計算の性質で、現実の仮説への新たな支持ではない。
