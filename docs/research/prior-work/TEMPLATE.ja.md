# 先行研究・取り組みの記録テンプレート

コピーして新しい記録を作成する。このテンプレート自体は文献の記録ではない。
不明な欄は`未確認`とし、読み手の推測で埋めない。該当しない欄は理由を添える。
次の未使用IDを確認し、見出しの`PW-XXX`、明示アンカーの`pw-xxx`、索引のリンク先をそろえる。

## PW-XXX — 資料名と、区別したい問題

- **記録日・閲読日**：YYYY-MM-DD JST。過去記録の索引追加日は再閲読日と分ける。
- **種類**：理論／規範論／方法批判／実証研究／介入評価／制度・運用資料／統合評価／データ／報道。
- **書誌・発行主体**：著者または部署、正式題名、原刊行年、巻号・頁、DOI・文書番号。
- **一次出典・版**：原本URL、刊行版／working paper／改訂版／転載の区別、関連ID。
  公刊日・電子掲載日・制度更新日・適用日・観測対象期間を混同しない。
- **対象・設計**：対象者・国・部門・期間・観測単位・分母・比較群・主要仮定。
  理論や規範論なら、実証の標本があるかのように書かない。
- **先行する貢献**：何を示した／実装した／区別した資料か。著者の報告と、こちらの評価を分ける。
- **適用範囲・限界**：識別できない因果、モデルの成立条件、対象外、価値判断、残る代替説明。
- **閲読範囲・未確認**：本文の節・印刷頁・表番号、要旨のみ、検索取得のみ、アクセス失敗、未読補遺、未再現コード。
  PDF枚数と印刷頁を区別する。未読と、原研究の弱点を同一視しない。
- **本研究への接続**：引き継ぐ点、競合する説明、こちらの推論・提唱、対象への移植をしない点。
- **次に確認すること**：不利な観測も含め、次に読む箇所・必要な記録・適切な比較。
- **利用条件・保存**：再配布の根拠、原文／データを保存したか。未確認なら全文をRepoへ追加しない。

### 制度・取り組みの場合に追加する欄

- 担当主体、管轄、対象、適用条件、改定版、公告日等の適用キー。
- 権限、義務、推奨の区別。支払元・仲介者・受取側と費用経路。
- 申請、承認、実入金、現物到達、実行、保護成果、継続のうち、どこまで記録があるか。
- 対象外・未申請・申請不能・却下・欠測の区別。既存の代替経路。
- 異議申立て、再評価、訂正、補償、解除の記録があるか。窓口の存在だけで訂正済みとしない。

### 登録前の点検

- 出版社の電子掲載日を原刊行年にしていないか。
- 同一研究の版・解説・再確認を独立した証拠に数えていないか。
- 原資料の結果、Repoの保存結果、こちらの新しい推論を区別したか。
- 対象者の改善を全体の純便益、制度の存在を保護完了、沈黙を同意や抑圧と呼んでいないか。
- 支持だけでなく、批判・反例・未確認事項を残したか。
- 文献の追加をF0の昇格や、学術的新規性の確定と呼んでいないか。
- ローカルリンクと該当箇所を確認したか。
