## 継続して追加する方法

1. [テンプレート](TEMPLATE.ja.md)で、一次出典・版・読めた箇所・貢献・限界を記録する。
2. 原研究の限界と、こちらの未読・未再現を分ける。批判の対象と射程も書く。
3. この索引へ追加し、同一研究の版・転載・解説・再確認を相互参照する。
4. 読み直して解釈が変わったら、日付・変更理由・旧解釈を残して追記する。
   原文の訂正・撤回が判明した場合も、出典と影響を記録し、黙って消さない。
5. 新しい主張は、外部研究の知見、Repoの結果、本研究の推論・提唱のどれかを明示する。

今回保存したのは書誌・短い独自要約・原本へのリンクであり、外部論文全文ではない。
Repo全体に新たなライセンスを付与しない。原文の再配布やデータ保存には個別の利用条件確認が必要。
出典の追加だけでF0を昇格させず、法的義務を免除したり、監査完了まで救助を待たせたりしない。
