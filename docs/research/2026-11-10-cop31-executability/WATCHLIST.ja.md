# COP31の決定と実施を区別して追う確認項目

2026-11-10 JSTの初期版。[分析](ANALYSIS.ja.md)から導いた観測設計であり、監視の自動実行・実地介入の登録ではない。
各資料の書誌は[SOURCES](SOURCES.ja.md)を参照する。

## 更新時に保存するもの

対象のID、文書名・版、公開日、観測基準日、取得日、単位・価格年・対象期間、分子・分母、
出典の該当箇所を保存する。後日の情報で初期記録を上書きしない。
現在値が読めない場合は`UNKNOWN`、対象外は理由付きで`NOT_APPLICABLE`とし、ゼロと分ける。

段階は、提案、共同声明、採択決定、予算・資金承認、契約発効、実入金、現物・サービス、
保護成果、継続、訂正を別の欄に置く。全案件がこの順に進むとは仮定せず、実際の依存関係を記録する。
決定の文言の強さと国内での執行権限も混ぜない。

| 資金とNCQG | 既存採択決定、S08 | 公的・民間、無償・融資・保証、額面・補助相当額、約束・実入金、重複、純移転を区別 | 将来の年額目標を当年の現金とみなす。返済や保証の偶発債務を消す |

| 損失と損害・FRLD | COP31向け制度報告、S11 | 後続の理事会決定、実入金、受取側への到達、未申請・不採択、非金銭的な損失 | 基金への拠出を被災者への受領とする。補償を被害の復元とする |
| 公正な移行・適応指標 | CMA 8の議題、S04 | 採択文書の役割・財源と、当事者の参加、申立費用、再評価、実際の訂正・補償 | 窓口数や指標数だけを公正さとみなす。申立ての少なさを問題の不存在とする |

閉幕時には、採択された条項の担当・資源・期限・見直しを確認できる。
ただし現場の入金・効果・継続に必要な追跡期間まで、閉幕日に圧縮することはできない。
その段階の進展と、まだ観測できない成果を並べて記録する。

## 最初の一案件に必要な記録

一対象・一作用・一資源の原則を維持する。国全体の温度効果や全予算を最初から一つの計算へ押し込まない。
候補例は、一地区の公共施設の冷却・給水など、提供サービスと維持期間を特定できる案件。
特定の国・案件を選定したわけではなく、既存の権利・保護を「追加事業」へ付け替えない。

| 記録群 | 必要な情報 |
|---|---|
| 対象と分母 | 保護の必要が生じる条件、対象・対象外、未申請・不採択・未実施、選定理由 |
| 権限と代替 | 適用法令・契約版、実施責任、既存の直接支援、独立して動ける救済経路 |
| 支払元と受取側 | 使える残高、実際に引き出せる信用、使途制約、相手先、予定・実入金、返済、既存義務 |
| 条件の依存関係 | 何が起きれば次へ進めるか、誰が確認するか、待機中の費用、解除・代替条件 |
| 現物と他の利用者 | 設備・人員・電力・水などの予約と実供給、他案件の利用、代替可能性 |
| 時計 | 必要性の把握、申請準備、申請、承認、契約発効、入金、着手、稼働、再評価 |
| 保護と継続 | サービス量、実際の保護指標、運営・保守・更新、財源、未払、未補償の損失 |
| 異議と訂正 | 窓口だけでなく、利用負担、再評価、訂正・補償、未解決、所要時間 |

これらの情報の取得権限・保管条件と、記録を作る側の負担を先に確認する。
個人情報を公開Repoへ置かない。監査のために救助や法的に必要な保護を待たせない。

## 判定は少なくとも四つに分ける

- **確認できた**：特定の条件・段階について記録がある。最終効果まで確認済みとは限らない。
- **不整合が確認された**：同じ案件の資金・現物・権限・時計が両立しない。代替経路の検討範囲を添える。
- **未識別**：同じ公開記録と整合する複数の状況で結論が割れる。欠測を楽観的に埋めない。
- **観測期間が足りない**：未入金・未完了・維持期間未到来を、永続的な失敗や成功にしない。

監査項目が揃っただけで処置を実行したり、総合点で人や国を順位づけたりしない。
次の実験を行うなら、既存の中心予測と今回の相互条件の候補を分離し、比較対象・意味幅・停止条件を新たに固定する。
