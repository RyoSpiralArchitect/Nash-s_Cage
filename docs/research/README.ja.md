## 蓄積の約束

- 原資料の貢献、原研究の適用範囲、こちらの未読・未検証部分を別に書く。
- 支持資料だけでなく、反例・対立する説明・方法への批判も同じ入口へ載せる。
- 制度の存在、承認、実入金、実行、保護の成果、継続を同一視しない。
- 規範として守りたいことと、データで確かめる予測を分ける。
- 既存台帳の閲読日を入口の更新日で上書きしない。過去の入力・結果・原稿を保存する。
- 全文・画像・コードを公開で読めることは、Repoへの再配布許諾を意味しない。
  原則として書誌、短い自分たちの要約、該当箇所、原本リンクを保存する。
